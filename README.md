# Muse Link（非公式・個人利用）

> **これは公式アプリではありません。** Muse / Meta 公式とは関係のない、個人が制作した非公式アプリです。

Muse が、あなたの PC の指定フォルダ（`C:\MuseWorkspaces`）の中で読み書きやコマンド実行をできるようにする連携エージェントです。接続は Tailscale + Windows 標準の OpenSSH で、専用ユーザー `muselink` と鍵認証だけを使います。初回起動時にセットアップウィザードが開きます。

## 本体アプリとの関係

Muse Link は [Muse Windows版（非公式）](https://github.com/yorukaze-luru/muse-windows) の**プラグイン**として動作します。

- インストール／アップデートは、本体アプリのプラグインページ（メニュー「プラグイン」）から、このリポジトリの Releases を使って行います
- エージェントの起動・停止は本体アプリが管理します（本体アプリの起動中のみ動作し、本体を終了するとエージェントも終了します）
- 単体のインストーラー（`Muse-Link-Setup-x.y.z.exe`）を Releases から直接入れることもできます

## アップデート

このリポジトリの Releases にある Link 用フィード（link.yml）を本体アプリのプラグインページが参照し、新版があればプラグインページからアップデートできます。

## 注意

- 未署名のため、Windows SmartScreen の警告が出ることがあります
- 非公式・個人利用のプロジェクトです。Muse / Meta 公式とは関係ありません

## 構成

- Electron 製のトレイエージェント＋セットアップウィザード
- リリースは GitHub Actions でビルドしています（タグ `v*` で下書きリリースを作成）
- アイコンと package-lock.json は base64 分割ファイルで格納し、ビルド時に復元します
